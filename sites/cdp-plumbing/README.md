# CDP Plumbing of Toronto — website

Static demo site for CDP Plumbing of Toronto (1344 Davenport Rd). Built 2026-10-27 as a replacement proposal for cdpplumbing.ca.

## Files
- `index.html` — homepage: hero with the "What's going on?" picker, trust strip, services, emergency band, recent work, how a call goes, reviews, service area + map, about, FAQ, callback form, footer. JSON-LD (Plumber + FAQPage) in `<head>`.
- `services/*.html` — five service pages (drain-cleaning, sewer-backup, leaks-and-pipe-repair, water-heaters, bathroom-and-kitchen). Generated by `gen_services.py` (edit the PAGES list and re-run `python3 gen_services.py`, or edit the HTML directly).
- `services.js` — all editable content: phone, picker answers, service cards, work cards, reviews. Edit text here.
- `main.js` — nav toggle, picker, grids, lightbox, form handling, reveal-on-scroll.
- `styles.css` — design tokens at the top (`:root`), then components, then responsive rules.
- `photos/` — real photos from CDP's Google Business Profile, caption bars cropped off, max 1600px, JPEG q82.
- `favicon.svg`, `apple-touch-icon.png` — house-and-drop mark drawn from their sign.
- `deploy.sh` — publishes to https://web.soichirosaimon.com/cdp-plumbing/ (sonysaimon/web-design, `sites/cdp-plumbing/`).

## Editing
- Phone number: `services.js` (`phone`, `tel`) **and** the `tel:` links in `index.html` / `services/*.html` (search `6475582622`).
- Reviews, work photos, service cards, picker text: `services.js`.
- FAQ: `index.html` (both the visible `<details>` and the FAQPage JSON-LD).
- Callback form: replace `YOUR_FORM_ID` in `index.html` with a real Formspree form id. Until then the form shows a "demo site" message instead of sending.
- Licence number: not published anywhere by CDP. Add it to the footer `.small` line and the FAQ answer once the owner supplies it.
